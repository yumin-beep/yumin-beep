# 강유민

게임 개발자를 지망하고 있는 강유민임.  
Unity와 C#으로 게임을 만들고 있으며, 팀 프로젝트와 게임잼을 통해 완성 경험을 쌓고 있음.

## 하고 있는 것

- Unity와 C#을 주로 사용함.
- 게임 프로그래밍과 팀 프로젝트를 계속 진행하고 있음.
- 필요한 기능을 직접 만들고, 문제가 생기면 끝까지 확인하는 편임.
- AI는 빠르게 시도하고 결과를 확인하는 도구로 사용하고 있음.

## 대표 프로젝트

- **AI 마피아** — 2026 GNGC 게임잼에서 만든 로컬 AI 추리 게임임. 전체 프로그래밍과 기획을 맡았음.
- **정화의 밤** — Unity 2D 로그라이트 팀 프로젝트임. 보스와 공격 패턴 구현을 맡았음.
- **[직업대전](https://github.com/yumin-beep/3djobbattle)** — Photon을 이용한 4인 점령전 게임임. 프로그래밍과 Unity 통합을 맡았음.
- **[요리왕천재](https://github.com/level0-team1/gaenojam1)** — 2일 게임잼에서 완성한 로컬 2인 요리 대결 게임임. 게임 진행과 채점, 인벤토리 등을 맡았음.
- **[회차용사](https://github.com/Level0-Nth-Hero/Nth-Hero)** — 카드와 덱 순환을 사용하는 Unity 2D 게임임. 카드·덱 시스템과 UI를 맡았음.
- **[럭키 더비](https://github.com/yumin-beep/lucky-derby)** — Three.js로 만든 3D 경마 게임임. 직접 기획하고 구현했음. [바로 플레이](https://yumin-beep.github.io/lucky-derby/)
- **[온글](https://github.com/Exxising/on-geul)** — 대화를 문서로 정리하는 AI 서비스임. 팀장과 백엔드·LLM 작업을 맡았음.

## 경험

- 대구대학교 게임개발동아리 LEVEL 0를 창설하고 초대 회장을 맡았음.
- [LEVEL 0 제1회 게임잼](https://itch.io/jam/level0-firstjam-gaenojam)을 주최하고 운영했음.
- 대구·경북 8개 대학 연합 게임잼 운영에 참여했음. 빌드업 해커톤을 마무리하고 릴리즈 해커톤을 준비 중임.
- 모두의 창업 1기 아이디어 심사 1라운드에 합격했음.
